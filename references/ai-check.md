# 行文自查

用适合载体的方式检查空泛表达、重复句式、无依据的结论与推理跳步。人工判断以原文和证据为准；词频与句长不用于判定作者身份或承诺通过检测。

## 一、什么时候跑

- 新写或大幅改写后通读相关正文。局部改写检查有变化的段落，纯排版无需扫描。
- 仅在中文正文且统计有助于定位问题时运行脚本。量化结果不参与通过或不通过的判定。
- 课程、期刊或用户要求 AI 使用声明时，独立记录实际用途和作者复核范围。

## 二、如何处理发现

先处理缺证据的强断言、逻辑跳步和误导性数据表述。模板句、冗词、节奏和用词根据语境修改。若触及事实、数值、结论或引用关系，回到相应证据并重新核验。

## 三、按文体选择通读重点

- 表达和段落：删去重复信息，修正无实际转折的连接句。技术术语、必要限定和能交代清楚来龙去脉的长段可以保留。
- 论证和归属：检查因果跳步、缺证据的强断言、推断范围，以及作者观察、公开资料和个人判断能否区分。缺失的经历、数据、局限与失败案例不能补写成事实。
- 数据和图表：按仪器分辨率、测量方法与实际统计口径写精度和不确定性。图题按模板和索引需要撰写，正文指出读者应该从图表读到的趋势或例外。
- 结构和引用：检查章节是否完成其功能、引注能否明确归属对应论断。受格式约束的摘要、标题和引注按载体执行。

## 四、可选的中文量化扫描

```bash
python "<SKILL_ROOT>/scripts/style-scan.py" body.txt
```

脚本接受 UTF-8 的 `.txt`、`.md`、`.tex`。优先使用仅含中文正文且保留段落边界的文本。DOCX 先提取正文，可用 Pandoc 转纯文本后去掉封面、参考文献、目录、表格和题注。LaTeX 清洗支持常见命令，复杂宏、外部 `input` 文件或自定义环境先转换/提取范围，再用纯文本扫描。英文正文人工复核；样本很短时只提供统计。

## 五、记录和复核

有实质发现时，在项目工作记录留下位置、发现和实际处理。复扫用于确认明确的行文问题已经处理；无需为让所有数值变化而拆散论证或增添模糊词。用户明确需要独立报告时，再输出逐条记录。

## 六、编辑边界

保持数据、公式、术语和引用关系准确。改完通读相关段落。用语应由载体和论证决定；不要按词表全局替换或给个人判断、限制表达等设配额。
