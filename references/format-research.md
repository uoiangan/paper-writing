# 格式调研：先找到“这一篇该长什么样”

先确认目标载体、模板版本和适用范围，标出真正影响成稿的空缺。只有这些空缺才需要补查范例或采用默认值。

## 一、先判定目标载体

| 载体 | 官方格式来源 | 典型产出 |
|---|---|---|
| 期刊投稿 | 期刊官网 Author Guidelines / LaTeX template | 提炼适用规格，按需保留模板 |
| 会议投稿 | 会议官网 Template（LaTeX/Word） | 同上 |
| 学位论文 | 学校研究生院“学位论文格式规范” | 同上 |
| 课程论文 | 教师给的模板或课程要求 | 同上 |
| 竞赛论文 | 当届官方《论文格式规范》 | 同上 |
| 用户没说 | 按同载体范例或工作稿现有规格补齐 | 注明采用的依据 |

**关键规则**：永远确认届次/版本/年份。往届规则、本 skill 的默认值、某个模板的习惯，都不得写成"官方要求"。

## 二、官方规则的检索

按顺序尝试，找到即停：

1. 用户提供的模板、规范文件和后续说明。记录文件名、版本或条款位置，并确认其约束版式、结构还是两者。
2. 官网页面：
   - 英文：`<venue> author guidelines`、`<venue> submission format`、`<venue> LaTeX template`
   - 中文：`<期刊名> 投稿须知`、`<期刊名> 论文模板`、`<学校> 学位论文格式规范`、`<竞赛> 论文格式规范 <年份>`
3. 官方 PDF（优先最新版，记录 URL 与发布日期）。
4. 学会/出版社的通用规范（如 IEEE Author Center、ACM Primary Article Template、GB/T 7713.2）。

只采信官网、官方 PDF、出版社页面。第三方博客、文库、网盘转载的"模板"只能作为线索，必须回到官方核实。

## 三、同主题优秀论文的检索

目的：拿到"这个领域的人实际怎么写"的证据，用来补官方规则没规定的部分。

### 选文标准

- 近 3–5 年（经典奠基文献可放宽）
- 同行评议期刊或顶会；综述、高被引、获奖论文优先
- 优先同课程、同一刊会或同类型载体，再看题目相近程度。
- 样例可用来填实质空缺。样本有限时注明依据为样例或编辑选择；多个同载体样例一致时再归纳为惯例。

### 检索词

- 英文：`<主题关键词> survey 2024`、`<主题> review`、`<主题> state of the art`
- 中文：`<主题> 综述`、`<主题> 研究进展`
- 也可用项目内已有的 `paper_search` 工具（OpenAlex + AnySearch），但搜索结果只用于发现候选，格式判断要读原文。

### 只提取格式特征

读论文时不要抄内容，记录这些：

- 章节层级与顺序（是否有 Related Work、Contributions、Limitations、Ethics Statement）
- 摘要长度与结构（是否分"背景-方法-结果-结论"四句）
- 关键词数量
- 图表密度：每千字几张图/表；图是矢量还是位图
- 公式编号方式；符号表是否有
- 段落平均长度；是否大量使用列表
- 引用密度：每段几条；是"作者+年份"还是数字编号
- 参考文献风格与条目完整度
- 版式印象：单栏/双栏、页边距宽窄、标题是否加粗、是否有强调色

### 归纳规则

- 在多份同载体样例中重复出现的特征可以记录为惯例，并保留样例出处。
- 只有 1 篇出现的，记为"个人风格"，不照搬。
- 各篇互相冲突时，以目标期刊/会议自己的论文为准。

## 四、把适用规格记入项目工作记录

```markdown
# 格式规格

目标载体：<期刊/会议/学校/课程/竞赛，含年份>
依据：[用户] 用户提供的模板 / [官方] URL / [惯例] 3 篇同主题论文

## 页面
- 纸张：A4
- 页边距：上下 2.5cm，左右 2.8cm        [官方]
- 栏数：单栏                            [官方]

## 字体字号
| 元素 | 字体 | 字号 | 来源 |
|---|---|---|---|
| 正文 | 宋体 | 小四（12pt） | [用户] |
| 一级标题 | 黑体 | 小三（15pt） | [惯例] |
| 图表题注 | 宋体 | 五号（10.5pt） | [默认] |

## 结构
1. 摘要  2. 引言  3. 方法 …              [官方]

## 摘要与关键词
- 摘要 ≤ 300 字，不分段                   [用户]
- 关键词 3–6 个                           [惯例]

## 图表与公式
- 三线表；表题在上，图题在下              [惯例]
- 公式按全文连续编号 (1)(2)…              [默认]

## 引用
- GB/T 7714-2015 顺序编码制               [官方]
- 文献 ≥ 15 条                            [用户]

## 篇幅
- 正文 6000–8000 字（目标，非硬约束）     [用户]

## 交付
- main.tex + refs.bib，编译出 PDF         [用户]
```

## 五、常见陷阱

| 陷阱 | 后果 | 正确做法 |
|---|---|---|
| 把往届竞赛规则当前届 | 结构、页数全错 | 查当届官方文件并记录年份 |
| 只搜"论文模板"不读同主题论文 | 格式对但写法不像该领域 | 优先采用同载体要求；只有空缺需要调研样例 |
| 把某本期刊的字号当成通用标准 | 换刊即错 | 每条规格标来源 |
| 直接下载第三方模板 | 可能含过时/错误设置 | 只从官网取模板 |
| 规格表写得太粗（只写"宋体小四"） | 标题、题注、参考文献全没规定 | 按上表逐元素列 |
