# 写作规范

语言、人称、术语以用户要求和目标载体为准。本文件是"没规定时"的默认标准。

## 一、段落与论证

- 一段一个论点。段落第一句给出论点，后面给证据或推理。
- 先事实后解释：先说数据/现象，再说它意味着什么。
- 避免"文字墙"：连续 3 段以上无图表公式时，考虑拆分或加小标题。
- 每节结尾不要强行总结；结论只在结论章写。

## 二、术语与符号

- 全文术语统一，建一份术语表；同一概念不换词。
- 缩写首次出现给全称：`长短期记忆网络（Long Short-Term Memory, LSTM）`，之后统一用缩写。
- 符号首次出现时定义；符号表放在方法开头；同一符号全文只表示一个量。
- 单位用 SI；数值与单位之间留细空格（LaTeX 用 `\,`）。
- 数字：计量用阿拉伯数字（3 个样本、12.5%），修辞性概数用汉字（三种方法）。
- 区分实测零、舍入后显示为零、低于检测限及数值计算的近零误差。只在检测限或容差有明确定义时使用 `<ε`，并注明依据和单位。

## 三、引用句式

- 转述而非罗列。不要写成"文献[1]研究了 A。文献[2]研究了 B。文献[3]研究了 C。"
- 改成归纳："已有工作从 A、B 两条路线展开[1-3]，但都未处理 C。"
- 引用必须支持该句主张；不能支持就换文献或删句。
- 不引用没读过的文献；不根据标题推测结论。
- 引用密度适中：每段 0–3 条，不是每句都挂引用。

## 四、时态与人称

- 中文：方法用"本文提出/构建"，结果用客观陈述"结果表明"；避免通篇"我们"。
- 英文：方法与贡献用现在时，实验操作用过去时，普遍结论用现在时。
- 不用第一人称单数（"我认为"）。

## 五、去 AI 腔（可检查清单）

以下模式出现即改：

| 模式 | 问题 | 改法 |
|---|---|---|
| "首先……其次……最后……" 套三段 | 结构僵化、信息密度低 | 按逻辑关系写，不按序数词 |
| "综上所述/总而言之" 每节都用 | 空转 | 删掉，直接给结论 |
| "具有重要的理论意义和现实意义" | 无信息 | 写具体价值或删 |
| "不仅……而且……" 连续排比 | 注水 | 拆成事实句 |
| 每段结尾都总结一句 | 重复 | 删 |
| 大量"有效地""显著地""极大地" | 无量化 | 换成数字或删 |
| 形容词堆叠（"高效、准确、稳定、可靠"） | 不可验证 | 每项给出指标 |
| 过渡句只连接不推进（"在此基础上……"） | 空转 | 直接写下一步内容 |

**判据**：删掉一句话，信息是否减少？不减少就删。

新写或大幅改写时按 `ai-check.md` 通读复核；中文正文可用脚本定位需要细看的表达。

## 六、避免夸大与绝对化

- 不用"首次""最优""完全"除非有证据；"最广""经典""常用"同样要有文献明说，没有就改成中性表述（"被广泛采用""常被用作测试矩阵"）。
- "显著"只在有统计检验时用，并给出 p 值或效应量；不要把"显著"当"明显"用。
- "同步上升/单调增长"必须逐点核对数据；出现回落时写"总体上升"，并指出例外点。
- 相关性不写成因果。
- 单数据集结果不外推为普遍规律。

## 七、英文写作要点（投英文刊/会议时）

1. 一句一个意思，平均 20–25 词，超过 35 词拆句。
2. 主动语态优先，方法部分可用被动。
3. 避免中式表达：`In this paper, we ...` 可用，但不要每段开头都用。
4. 冠词与单复数逐句检查（中文作者最常见错误）。
5. 术语首次出现给全称与缩写，之后统一。
6. 数字与单位：`5 mm`、`10%`、`p < 0.05`（斜体 p）。
7. 引用风格严格按模板，不混用作者-年份与数字编号。
8. 连接词多样化：however / moreover / in contrast / consequently，不重复同一个。
9. 不写 `very`、`quite`、`obviously` 这类主观副词。
10. 投稿前用拼写检查（英式/美式统一）。

## 八、绝不做的四件事

1. 编造数据、实验、图表。
2. 编造文献、DOI、卷期页、作者名单。
3. 把推测写成结论。
4. 把本 skill 的默认值或往届经验写成"官方规定"。
